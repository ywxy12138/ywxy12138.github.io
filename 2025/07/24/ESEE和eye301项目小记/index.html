  1. 在 Python 中使用eval()解析字符串”[{patient_id:1}]”会报错，具体错误为NameError: name ‘patient_id’ is not defined，字符串”[{patient_id:1}]”的语法在 Python 中存在歧义：

从结构上看，它试图表示一个包含字典的列表，类似[{key: value}]。
但字典的键patient_id被视为未定义的变量（而非字符串键）。
在 Python 中，字典的键若为标识符（如patient_id），会被解析为变量名，而不是字符串。由于patient_id未被定义，eval()执行时会找不到该变量，从而抛出NameError。解决方案是将字典的键改为字符串形式。

  2. python中typing包中的Annotated的作用是？

    其是一个特殊的类型提示工具，用于为类型添加额外的元数据，在保留原始类型信息的同时附加一些可被工具、库或框架读取并利用的辅助性元数据。
    语法：Annotated[type, metadata1, metadata2, ...],其中type为原始类型，后续参数为元数据，用于附加额外信息。

  1. 0.0.0.0,localhost(127.0.0.1)和服务器IP的区别:
    1. 0.0.0.0:所有”网络接口”的占位符,不是一个具体的地址,表示”监听服务器上所有可用的网络接口”,当绑定某一端口时,会同时监听服务器的内网IP,外网IP和localhost等所有网卡的端口,因此,外部用户可通过服务器端的”主机号”访问此服务.
    2. localhost为本地回环地址,仅指向服务器本身的”本地回环接口”,只能在服务器内部访问,外部用户无法通过服务器的”主机号”访问此服务,只能通过服务器本身访问.
    3. 服务器IP:具体网卡地址,是服务器物理网卡上绑定的实际IP,若服务绑定到某一端口,系统会尝试将其绑定到该IP对应网卡上,若IP未被识别则会报”无法分配地址”的错误,一般来说使用0.0.0.0时,服务会自动绑定到服务器所有有效网卡,而给出具体IP不一定有对应的网卡就不能正常分配地址.
