C++ 算法库 <algorithm>中的equal函数的参数疑惑

发表于2026-11-10|更新于2026-11-11|学习笔记

为什么第二个容器只传 begin()？

学习 <algorithm> 中的 std::equal 时，遇到了这样的调用：

既然是在比较两个容器的元素，为什么 v1 要传 begin() 和 end()，而 v2 只传一个 begin() 就够了？如果没有 v2.end()，函数怎么知道什么时候结束？

关键在于，这个重载以第一个范围的长度为准。v1.begin() 和 v1.end() 确定要比较的范围，v2.begin() 确定第二个范围的起点；第二个范围需要参与比较的元素数量，由第一个范围决定。标准草案中的定义

两个迭代器同步前进

begin() 指向第一个元素，end() 指向最后一个元素之后的位置，不能解引用。因此 [v1.begin(), v1.end()) 是一个左闭右开的范围。

每比较一对元素，两个迭代器就一起向后移动。第一个迭代器到达 last1，比较就可以结束。若第一个范围有 N 个元素，第二个范围参与比较的就是从 first2 开始的 N 个元素。

所以，不传 v2.end() 并不意味着函数自动知道了 v2 的大小。它只拿到了一个起点，调用者需要保证从这个位置开始有足够的元素。
