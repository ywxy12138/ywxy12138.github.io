能不能只修改脚本第一行？

进一步想了一下：既然是需要先进入 Zsh，能不能直接在脚本第一行指定，而不用修改桌面启动器？

可以。针对当前这份脚本，可以写成：

第一行称为 shebang，用于在直接执行脚本时指定解释器。在本机 Linux 环境下，这里指定的是 /bin/zsh，并向它传入 -i 参数。

单独写 #!/bin/zsh 还不够，关键在于后面的 -i。

-i 是 interactive，即强制交互模式。交互式 Zsh 会读取 .zshrc，从而执行我放在其中的 NVM 初始化配置，再运行脚本里的 npx 命令。它并不要求脚本接下来一定要等待人工输入。

这里也需要区分几个概念：

配置或参数 作用
Terminal=true 让桌面启动器在终端窗口中运行程序
#!/bin/zsh 直接执行脚本时使用 Zsh 解释
-i 强制交互模式，使 Zsh 读取 .zshrc
.zshrc 中的 NVM 配置 加载 NVM，设置所选 Node.js 版本的环境

因此，-i 本身不负责激活 NVM，也不负责打开终端窗口；它让 Zsh 读取配置，再由配置完成 NVM 初始化。
