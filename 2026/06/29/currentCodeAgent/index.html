常见代码智能体

Cursor

代码库理解

Cursor 的代码库嵌入模型为 Agent 提供深度理解与高效记忆。

接入顶级模型

可自由选择来自 OpenAI、Anthropic、Gemini 和 xAI 的前沿模型。

范围化变更

使用自然语言进行定向编辑或运行终端命令。

多行编辑

在多行范围内获取建议修改

智能重写

自然输入，补全代码

一键Tab

在Tab键处及跨文件快速完成代码编辑。

CLI

可在任意终端或脚本中运行代理，直接与最新大模型(Anthropic、OpenAI、Gemini 等)进行前沿对话。
在任何的IDE中，Cursor CLI都可与现有工作流集成。
还有编写强大的脚本与自动化的能力，自动更新文档、触发安全审查的能力。

直接在终端执行命令行。
还可以通过如下方式开启非交互模式：

通过如下方式继续此前的对话，在交互中保持上下文：

# 列出所有历史聊天记录
cursor-agent ls

# 恢复最新对话
cursor-agent resume

# 恢复指定对话
cursor-agent --resume="chat-id-here"


尝试了一下，对于越界的判断十分执着，如上图。

Bugbot评审

捕捉真实漏洞与安全问题，以较低误报率检测最棘手的逻辑缺陷。
启用后，Bugbot 会在新 PR 上后台自动运行。
坚持代码规范，定义规则、落实最佳实践，并设置项目特定的规范。
快速解决问题，Bugbot 与 Cursor 深度集成；一键启动智能体，搭建修复方案。

一键导入

可直接从VS中导入扩展、主题和按键映射。

MCP服务器

同外部工具和数据库直接连接。

规则与记忆

通过可复用且有作用域的指令自定义模型行为。

自定义命令

在团队项目中使用和管理可复用的提示。
